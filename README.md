# CS Beauty & Concept — website

Site de uma página do espaço de beleza CS Beauty & Concept (Sobral de Monte Agraço).

- Publicado com GitHub Pages: https://valerialazarinfo-lab.github.io/cs-beauty/ (cada push a `main` atualiza o site).
- Tudo está em `index.html` (HTML, CSS e JavaScript juntos). Sem build nem dependências.
- Imagens: `img/hero/` (topo), `img/g/` (galeria), `img/ig/` (publicações do Instagram), `img/partilha.jpg` (pré-visualização em redes sociais).

## Regras para alterações
- Testar no telemóvel antes de enviar para `main` — o site é público.
- Imagens comprimidas (JPG, largura até ~1600 px).
- Só usar fotografias e contactos autorizados pela cliente.
- Português de Portugal.
